# Task 3 – SQL for Data Analysis

## Project Title
E-Commerce Data Analysis Using SQL

## Objective
The objective of this task was to perform data analysis using SQL on an e-commerce database. The database was created and analyzed using SQLite and DB Browser for SQLite.

## Tool Used
- DB Browser for SQLite
- SQLite

## Database Tables
- Customers
- Products
- Orders
- Order Items

## SQL Concepts Demonstrated
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- SUM()
- AVG()
- JOIN
- Subqueries
- Views
- Indexes

## Analysis Performed
The project analyzed customer information, product prices, product categories, orders, and order items using SQL queries.

## Files Included
- ecommerce_task3.db – SQLite database
- Task3_SQL_Queries.sql – SQL queries used for analysis
- Task3_GroupBy_SUM.png – GROUP BY and SUM result
- Task3_JOIN.png – JOIN result
- Task3_Subquery.png – Subquery result
- Task3_View.png – View result
- Task3_GroupBy_AVG.png – GROUP BY and AVG result
- Task3_SELECT.png – SELECT query result

## Conclusion
This task provided practical experience in SQL-based data analysis, including filtering, sorting, aggregation, joining multiple tables, subqueries, views, and indexes.
